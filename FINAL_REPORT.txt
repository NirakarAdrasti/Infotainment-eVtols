## 📞 TROUBLESHOOTING

### Server won't start
```bash
# Kill existing process
netstat -ano | findstr :8000
taskkill /PID [PID] /F

# Try different port
python -m http.server 9000
```

### Module not found errors
```bash
# Ensure venv is activated
myenv\Scripts\activate.bat

# Reinstall packages
pip install -r requirements.txt
```

### Port already in use
- Change port: `python -m http.server 9000` (instead of 8000)
- Or: `uvicorn main:app --port 8001` (instead of 8000)
